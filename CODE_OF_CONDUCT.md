# Code of Conduct

## Our Standard

This project should remain a respectful academic and engineering space. Everyone
working on it is expected to:

- Use welcoming and inclusive language.
- Give constructive technical feedback without personal attacks.
- Credit other people's work accurately.
- Treat assignment, lecturer, and student information with care.
- Prefer private correction for honest mistakes and public correction for public
  misinformation.

## Unacceptable Behaviour

Unacceptable behaviour includes harassment, discrimination, plagiarism,
deliberate misrepresentation of authorship, sharing private academic
information without permission, or using the project to attack another person.

## Enforcement

For coursework use, concerns should be raised through the appropriate Singapore
Polytechnic module or class communication channel. For public repository use,
maintainers may remove comments, close issues, or restrict participation when
behaviour harms the project community.
