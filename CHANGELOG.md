# Changelog

All notable changes to this project should be documented here.

## 0.1.0 - 2026-04-29

- Renamed and documented the project as SP DSAA Newspaper Restoration.
- Reorganised source code into the `src/newspaper_restoration` package.
- Moved sample, expected-output, trie-dump, and legacy text files into `data`.
- Added pytest coverage for trie operations, restoration, persistence, and
  advanced features.
- Added CI for linting, formatting, tests, coverage, Bandit, and dependency
  auditing.
- Added README, code of conduct, contributing guide, security policy, authors,
  assignment context, data, usage, architecture, and testing documentation.
- Improved typing, docstrings, deterministic ordering, and CLI exit behavior.
