# Documentation

Project documentation lives here.

- `USAGE.md` explains how to run and use the CLI.
- `ARCHITECTURE.md` describes the package design.
- `DATA.md` explains the sample data folders and file format.
- `TESTING.md` documents local and CI quality checks.
- `ASSIGNMENT_CONTEXT.md` records the coursework context.
- `MAINTENANCE.md` captures release and housekeeping notes.
